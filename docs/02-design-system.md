# 02. Дизайн-система — WITZIGHAUSEN RESIDENZ

> ⚠️ Только этот подпроект. Свой файл `assets/css/styles.css`, свои токены. Не смешивать с donau-hoefe / апартаментами.
> Направление: тёплый минимализм экспозе — бежевый «бумажный» фон, тауп-акцент, тонкая крупная типографика (концепт «линии рояля»).

## Цвета (токены)
- `--bg` #F1EDE9 — фон страницы (тёплый беж)
- `--bg-2` #E7E0D8 — мягкая панель/секция
- `--paper` #FBF9F6 — карточки (тёплый почти-белый)
- `--ink` #1C1B17 — основной текст (глубокий тёмный из палитры отделки)
- `--ink-2` #6A635A — вторичный текст
- `--line` #DCD5CB — границы/разделители
- `--accent` #A99581 — тауп: eyebrow, акценты в заголовках, пины, линии таблиц
- `--accent-deep` #8A7359 — тёмный тауп для текста-акцента (контраст AA на беже)
- `--blue` #56B4D3 — только дорожные бейджи (B28/A7)
- `--ok` #4E7A5B, `--err` #B4472E
- Палитра отделки (акцент-точки/декор): #E5D9CB · #CEBAA3 · #B98F63 · #5D3D26 · #1C1B17

## Типографика
- Один шрифт — **Roboto Flex** (Google Fonts), веса 300/400/500/600.
- Заголовки — 300 (light), крупно, letter-spacing −0.01–−0.02em (рояльная тонкость). Мелкие лейблы/eyebrow — 500, UPPERCASE, letter-spacing +0.14em.
- Шкала (clamp, без скачков): h1 clamp(2.6rem,6vw,5rem) / h2 clamp(1.9rem,4vw,3rem) / h3 1.25rem / body 1rem–1.0625rem. LH: заголовки 1.08, текст 1.65.

## Сетка и ритм
- Контейнер max-width 1200px, боковые поля clamp(20px,5vw,48px).
- Вертикальный ритм: секции padding-block clamp(64px,9vw,120px). Шаг 8 (8/16/24/32/48/64/96).
- Радиусы: --r-sm 6px, --r 12px, --r-lg 20px. Тени очень мягкие, тёплые.

## Кнопки (единый `.btn`)
- `.btn` (база) = primary: заливка `--ink`, текст `--bg`.
- `.btn--outline` — контур `--accent`, текст `--ink`.
- `.btn--ghost` — текст-ссылка со стрелкой.
- Размер база 52px, радиус --r-sm, Roboto Flex 500. hover — подъём/затемнение; focus-visible — кольцо `--accent`; disabled — opacity .5.

## Компоненты
- `.eyebrow` + `.rule` — тауп-лейбл + тонкая линия (заголовок секции).
- `.split` — 2 колонки медиа/текст (адаптив в 1).
- `.appart-card` — карточка featured-квартиры: Grundriss на беже + имя + площадь + «Grundriss ansehen».
- `.price-table` — таблица 22 квартир (Nr · Residenz · Fläche · Preis). На мобилке → карточный режим (data-label).
- `.spec-list` — Baubeschreibung: иконка + текст, сеткой.
- `.feature` (Witzighausen) — иконка + заголовок + текст; `.stat` — крупное число + подпись.
- `.band` — полноширинная секция с фоновым фото + оверлей.
- `.map` — карта с пином.

## Принципы
- Меняешь компонент → меняешь везде.
- После правки — проверять overflow на 500/1440 (iframe-проба), мобилку, перекрытия.
- alt у картинок; focus-visible; контраст ≥ AA; `prefers-reduced-motion` уважать.
- Anti-cache `?v=N` на css/js.
